作業一 Ch7_3_4 — FOREIGN KEY 外鍵關聯建置
✅ 已完成

在【教務系統】資料庫中建立【班級】資料表，並以 FOREIGN KEY 將其與【學生】、【教授】、 【課程】三張父表建立多對多關聯。

複合主鍵
學號 + 教授編號 + 課程編號
外鍵關聯
3 組 REFERENCES 綁定
執行環境
SQL Server 2022 / SSMS
🛠️ SSMS 執行步驟
  1. 1掛載 教務系統.mdf，確認【學生】【教授】【課程】三張父表存在
  2. 2清除【學生】表重複的 S108（解決訊息 1505）
  3. 3為三張父表的參照欄位補上 PRIMARY KEY
  4. 4建立【班級】表並綁定 3 組 FOREIGN KEY
  5. 5執行 SELECT * FROM 班級 與 sp_help 驗證並截圖
⚠️ 課本使用 char/varchar，實際資料庫為 nvarchar；外鍵與主鍵型別長度必須完全一致，所有指令已統一修正為 nvarchar。
