## 🛠️ 使用 SSMS 完成作業

本作業的【教務系統】資料庫附有 `教務系統.mdf`，所有指令皆在 **SSMS → 新增查詢** 中逐段執行（`F5` 執行）。

### 步驟一：掛載資料庫

1. 開啟 **SQL Server Management Studio**，連線到你的 SQL Server 執行個體（localhost）。
2. 在「物件總管」中右鍵點選 **資料庫 → 附加**（Attach）。
3. 選擇 `作業一/教務系統.mdf` 檔案，確定掛載，資料庫名稱設為 **教務系統**。
4. 展開 `教務系統 → 資料表`，確認已存在 **學生**、**教授**、**課程** 三張父表。

### 步驟二：執行作業指令

於 SSMS 中按 `Ctrl + N` 新增查詢，貼上以下四段指令並依序執行：

| 階段 | 目的 | 核心指令 |
| :--- | :--- | :--- |
| STEP 1 | 清除【學生】表中重複的 `S108`（解決訊息 1505） | `ROW_NUMBER()` + `DELETE` |
| STEP 2 | 為三張父表的參照欄位補上 `PRIMARY KEY` | `ALTER TABLE ... ADD PRIMARY KEY` |
| STEP 3 | 建立【班級】資料表並綁定 3 組 `FOREIGN KEY` | `CREATE TABLE 班級 (...)` |
| STEP 4 | 驗證結果並輸出截圖 | `SELECT * FROM 班級;` / `EXEC sp_help '班級';` |

### 步驟三：檢視成果

* **資料表結構**：於「物件總管」展開 `教務系統 → 資料表 → 班級 → 資料欄位」。
* **外鍵關聯**：右鍵 `教務系統 → 資料庫關聯圖 → 新增資料庫關聯圖`，加入 `班級`、`學生`、`教授`、`課程` 四張表，即可看到 3 條外鍵連線。
* **執行結果**：於 SSMS 下方切換到 **「訊息 (Messages)」** 分頁檢視指令執行結果（錯誤清單可能因 IntelliSense 快取未同步而顯示舊錯誤，可按 `Ctrl + Shift + R` 重新整理）。

### ⚠️ 型別注意事项

課本投影片使用 `char(4)`、`char(5)`、`varchar(8)`，但【教務系統】資料庫中相關欄位實際為 **`nvarchar`**。外鍵與被參照的主鍵**型別與長度必須完全一致**，因此本作業所有指令已統一修正為 `nvarchar(4)`、`nvarchar(5)`、`nvarchar(8)`。
